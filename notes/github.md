## Bài 17: Sửa file bằng Claude Code

Trước khi lưu thay đổi, nên kiểm tra lại nội dung đã sửa để tránh lỗi:

```bash
git status
git diff
```

- `git status` cho biết file nào đã thay đổi.
- `git diff` cho xem chi tiết từng dòng đã sửa (dòng thêm, dòng xóa).

Chỉ commit sau khi đã xem và xác nhận thay đổi là đúng ý.
